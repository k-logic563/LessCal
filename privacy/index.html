LessCal プライバシーポリシー

LessCalは、Googleカレンダーの表示構成をプリセットとして保存し、簡単に切り替えるためのChrome拡張機能です。

最終更新日：2026年8月25日

1. LessCalが処理する情報

LessCalは機能提供のため、次の情報をブラウザ内で処理します。

  • Googleカレンダー上のカレンダー表示名
  • カレンダー識別情報（GoogleカレンダーのDOM上のdata-id）
  • 各カレンダーのON／OFF状態
  • ユーザーが入力したプリセット名
  • プリセットに含まれるカレンダー識別情報
  • プリセットの表示順などの設定情報

2. 利用目的

処理する情報は、次のLessCal機能を提供する目的にのみ使用します。

  • Googleカレンダーの現在の表示構成をプリセットとして保存すること
  • 現在の表示構成と保存済みプリセットが一致するか判定すること
  • 保存済みプリセットへ表示を切り替えること
  • 保存済みプリセットを現在の表示構成で更新すること
  • プリセットの表示順を保持すること

3. 保存場所と保持期間

プリセット名、プリセットに含まれるカレンダー識別情報、作成・更新日時、表示順はChrome Storageへ保存され、ユーザーのブラウザ内で保持されます。開発者が管理する外部データベースには保存しません。

保存した情報は、ユーザーが削除するかLessCalをアンインストールするまで保持されます。

4. 外部送信・第三者提供

LessCalが処理する情報について、次の行為は行いません。

  • 開発者が管理する外部サーバーへの送信
  • 第三者への提供または販売
  • 広告またはマーケティング目的での利用
  • アクセス解析、利用分析またはトラッキング目的での利用

5. データの削除

個別のプリセットは、LessCalのPopupにある削除操作から削除できます。LessCalをChromeからアンインストールすることで、拡張機能がChrome Storageへ保存したデータを削除できます。開発者側ではユーザーデータを保存していないため、開発者へ削除を依頼する必要はありません。

6. Limited Use

LessCalが取得または処理するユーザーデータは、LessCalの単一用途であるGoogleカレンダー表示プリセット機能の提供にのみ使用します。それ以外の目的で使用、転送または共有しません。

7. 使用しない技術・サービス

LessCalは次の技術・サービスを使用しません。

  • Google Calendar API
  • Google Workspace API
  • OAuth認証
  • 外部から取得して実行するリモートコード
  • GA4などのAnalytics、Cookieまたはトラッキング

8. Googleカレンダーへのアクセス

LessCalはGoogleカレンダーのページ上でのみ動作し、表示プリセット機能に必要な範囲でページ内のカレンダー一覧とON／OFF状態を読み取り、ユーザーが選択したプリセットを適用します。

9. 改定

本ポリシーを改定する場合は、このページで改定内容と更新日を公開します。
